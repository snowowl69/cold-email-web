🔌 API Endpoints

POST /api/upload-contacts
Upload and parse CSV/Excel contact file. Returns parsed contact list.
POST /api/upload-attachments
Upload campaign attachment files (resume, cover letter, etc.)
DELETE /api/attachments/:filename
Remove an uploaded attachment from the campaign
POST /api/send-emails
Start sending bulk emails. Accepts: contacts, template, attachments, delay, limit
GET /api/send-status
Server-Sent Events (SSE) stream for real-time sending progress
POST /api/stop
Stop an active email sending campaign

⚙️ How It Works - Deep Dive

📥 Contact Upload Process

1️⃣ User uploads CSV/XLSX file → Multer saves to uploads/ folder

2️⃣ XLSX library parses spreadsheet → Extracts Name, Email, Company, Position

3️⃣ Validates email addresses → Skips rows without valid emails

4️⃣ Returns contact list to frontend → Displays in editable table

✉️ Email Sending Pipeline

1️⃣ User provides Gmail credentials + App Password (stored in browser localStorage)

2️⃣ Template placeholders {name}, {company}, etc. get replaced per contact

3️⃣ Nodemailer creates SMTP transporter with Gmail configuration

4️⃣ Sends emails with configured delay between each message

5️⃣ Broadcasts SSE updates to show real-time progress on frontend

6️⃣ Records sent recipients in sent_log.json to prevent duplicates

🔄 Real-time Progress Updates

• Backend maintains SSE client connections

• For each email sent, broadcasts: {status: 'sent', email: '...', progress: '2/100'}

• Frontend EventSource listener updates UI instantly

• Dry-run mode previews email without actually sending
